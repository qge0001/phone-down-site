隐私政策

本政策说明「放下手机」如何处理你的个人信息。

你的信息

使用记录、设置和你填写的提醒内容保存在你的设备上。这些内容不会发送给开发者或广告服务。

广告服务

在提供经验加速卡功能的地区，当你选择广告相关功能时，Google AdMob 及其同意服务可能预加载或展示广告，处理 IP 地址、设备相关标识、广告展示与互动，以及性能和崩溃信息，用于广告投放、分析、诊断与防止欺诈。IP 地址也可能用于估计大致位置。相关信息的处理、保存和删除适用 Google 隐私政策。中国大陆 App Store 地区不提供经验加速卡和广告功能。

系统追踪权限

在你主动领取经验加速卡时，应用可能询问系统追踪权限。只有你允许后，Google 才可使用设备广告标识符，结合其他公司应用或网站的数据提供个性化广告和衡量广告效果。拒绝或系统限制追踪时，广告请求不提供设备广告标识符，并关闭广告个性化；你仍可观看广告领取卡片和正常使用挑战。你可随时在 iPhone 系统设置中更改追踪权限。

隐私选择

是否领取经验加速卡及使用卡片由你选择。需要征求广告同意时，会在广告展示前提供相应提示；需要调整广告隐私选择时，可通过应用设置中的广告隐私入口操作。系统追踪权限和广告同意分别管理，拒绝系统追踪不会减少卡片奖励。

保存与删除

设备上的记录会保留至你删除应用。删除应用后，这些记录会从设备移除；系统备份中的副本由你的备份设置管理。开发者无法为你恢复已删除的记录。

网站与反馈

访问本网站时，GitHub 会记录并保存访问者的 IP 地址，用于安全目的。本网站不另设访问统计或广告。通过 GitHub 提交反馈时，你提交的内容会由 GitHub 处理；公开反馈中请勿填写私人信息。外部网站适用各自的隐私政策。

政策更新与隐私问题

信息处理方式发生变化时，我们会更新本政策并注明日期。如有隐私相关问题，请通过「联系我们」页面获取支持。
